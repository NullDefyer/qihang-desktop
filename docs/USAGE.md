# 使用说明

## 本地服务

新安装服务列表为空。选择“添加服务”，从左侧模板选择中间件，再选择本机目录、修改名称、启动命令和可选端口。模板不会下载或安装中间件；请先安装对应 Windows 发行包以及 JDK、Erlang 等前置依赖。

端口只是界面元数据，真实端口需要在中间件配置里设置。启动命令以当前 Windows 用户权限执行；停止时终止由启航启动的完整进程树。可批量启停。

宽窗口左侧显示服务、右侧显示日志，小窗口上下排列。拖动中间分隔条或使用方向键调整，双击/Home 恢复。服务卡片按可用空间自动变成完整、紧凑或图标布局，也可固定展示方式。

启动日志最多缓存最近 500 行，支持按服务/关键词筛选、自动跟随、换行和横向滚动。阅读历史时暂停跟随，回到底部恢复。复制/导出针对当前筛选；文本导出最多 2 MB，需选择保存位置。不自动持久化进程日志；Nacos、Redis 等自身的日志文件由各服务配置决定。

## 远程

添加 SSH 地址、端口、用户名，选择密码或私钥认证。首次连接前核对 SHA256 主机指纹；地址、身份改变后需重新认证。服务器用户需要有读取相应系统指标与 Docker 的权限。需要 sudo 时，只支持已配置的免密 sudo；不代替管理员修改权限。

四个页签：

- **概览**：Linux CPU、内存、根磁盘、非 loopback 网络速率，15 分钟内存曲线和应用内阈值提醒。CPU/网络首次采样未知，第二次有效采样后才有速率。
- **容器**：Docker 状态、CPU/内存、端口、重启次数和启动时间等只读信息。没有启停/删除远程容器操作。
- **数据库**：MySQL/MariaDB、Redis 的连接数、只读会话及版本/权限允许的事务、锁等待等指标。固定 SELECT/SHOW/INFO 等查询，不采集 SQL 文本，不提供写入或终止会话操作。
- **日志**：容器 stdout/stderr，最近 100/500/1000 行及后续输出，筛选、暂停、跟随、换行、横向滚动、复制与导出；最多缓存 2000 行。容器内部独立日志文件不在采集范围。

数据库地址按 **SSH 服务器视角** 填写。例如数据库容器在该服务器上，将 `13306:3306` 发布到宿主机后，填写 `127.0.0.1:13306`；不要把容器内部端口或本机电脑地址当成 SSH 服务器地址。

数据库连接经过临时绑定 loopback 的 SSH 隧道，数据库端点需支持普通 TCP，目前不支持额外的数据库 TLS。监控账号权限不足时对应指标显示未知。MySQL 全量会话可能需要 PROCESS；事务/锁数据取决于 information_schema/performance_schema 权限和数据库版本。Redis 可用指标受 INFO、CONFIG GET maxclients、CLIENT LIST 权限影响。

可选记住 SSH/数据库密码，使用 Windows 当前用户 safeStorage 加密；默认不保存。取消记住可清除密文，私钥口令不持久化，私钥只保存路径。导出备份不含密码或私钥内容。

保持 SSH 连接且未暂停时，切到笔记等页面仍继续采集。断开/退出后停止；不提供离线监控，不影响远程容器运行。曲线、会话和接收的日志只保留在当前应用会话内存，手动导出除外。

## 日常工具

- **笔记**：独立纯文本、自动保存、搜索、全部/已置顶筛选，不与服务绑定。
- **待办**：编辑、删除、8 秒撤销；完成和提醒事件进入历史，可搜索筛选。删除提醒历史不删除源任务，重新打开已完成项保留身份并清除过期提醒时间。
- **倒计时**：自定义名称、目标时间或时长；时长支持暂停/恢复/重置。按名称、天数、HH:MM:SS 三列展示。
- **快捷启动**：打开软件、文件、目录或 HTTP(S) 网址。
- **翻译**：中文/英文互译，使用 MyMemory 在线服务；点击时发送原文，单次 500 UTF-8 字节，不保存翻译历史。
- **命令收藏**：保存 PowerShell/CMD 命令与可选工作目录，先预览再确认执行；一次一个任务，输出保留最近 512K 字符，可停止该任务进程树。只保存命令，不保存输出。切换页面不中断正在执行的任务。
- **C 盘清理**：仅检查 C 盘的用户临时目录、Windows Temp、D3DSCache、Edge/Chrome Cache/Code Cache/GPUCache。扫描后默认不勾选，选择并确认后才永久删除至少 7 天未变化的普通文件。跳过链接、硬链接、占用/权限失败与应用/数据/备份目录，不删除文件夹。上限约 20 秒/30000 项，结果 30 分钟有效；部分统计会明确标注。

托盘双击或菜单可重新打开窗口，全局搜索默认 Alt+Space，可修改或关闭。提醒仅在程序运行或驻留托盘时有效，受 Windows 通知设置影响。

## GitHub 高星项目

无需登录，支持关键词、语言、最低星数、topic 分类和星数/最近推送排序。每页 20 条，GitHub 仅允许前 1000 条搜索结果。查询缓存 5 分钟，刷新可重新请求；不绕过接口限流。失败、超时、部分结果与限流恢复时间均显示提示。

仓库按钮用系统浏览器打开规范化的 github.com 项目链接，不自动 Star。简介保留项目原文，头像来自 GitHub；查询/令牌不会保存。

## 存储、备份和卸载

普通安装默认：

```text
安装目录/
  Qihang.exe
  data/
    qihang-state.json
    remote-servers.json
    storage-locations.json
  backups/
```

全用户安装使用 Windows SID 子目录隔离数据。目录指针留在安装默认 data（或 SID 子目录）；设置里可分别更改数据和备份目录。数据迁移经复制校验并保留原文件，目标不能已有启航数据；备份目录变化只影响后续备份，旧备份不移动。

开发模式的业务数据与目录指针使用 Electron userData；Electron 缓存和加密元数据仍在用户配置目录。浏览器预览只使用浏览器本地存储，不是桌面业务数据。实际目录可在设置里查看。

首次启动发现旧记录时，明确选择全新开始/导入/取消。全新开始不自动导入远程服务器；默认目录已有记录时用 fresh-UUID 子目录，不覆盖原始文件。

每日自动备份保留最近 14 个每日快照；手动/恢复前备份另存，恢复配置前要求停止本工具启动的本地服务。备份不含保存的远程密码。

交互卸载询问删除/保留/取消，默认保留。删除只处理已知应用记录和格式有效的启航备份，保留自定义目录中的其他文件。历史外部位置和自行导出的副本不会追踪清理。升级和静默卸载保留数据。
